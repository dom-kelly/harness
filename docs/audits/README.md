# Audits

Dated, point-in-time codebase audits, one file per audit:
`YYYY-MM-DD-<model-or-scope>.md`. These record what was true at the time, so
they are exempt from the docs temporal check.

Each audit has: a severity-ranked findings table (evidence as file and line,
impact, effort, one-way/two-way door), accepted residuals it deliberately did
not re-report (from [security.md](../contributing/security.md)), known
false-positive risks, what was not covered, and follow-up issue links.
